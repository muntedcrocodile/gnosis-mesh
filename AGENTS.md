# AGENTS

- Always use the .venv environment for running python and install packages by adding them to the `requirements.txt` file and then installing everything in that file with `pip install -r requirements.txt`. Always use the venv if one does not exist create it.

- Always use type hints in Python and prefer using click for command line argument parsing when doing commandline arg passing
- Add __pycache__ to .gitignore when working with Python projects

- When you encounter `<| something here>` that is the trigger to insert ur implementation into that point in the file
